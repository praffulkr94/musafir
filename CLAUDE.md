# CLAUDE.md

Musafir — personal travel-memory web app (React 19, TypeScript, Vite, React Router, Zustand persist).

- Brief and scope: `docs/PLAN.md`. Product truth: `PRODUCT.md`. Visual system: `DESIGN.md`
  (built from `docs/design.md`, the Airbnb-derived system, with Poppins everywhere).
- Phase 1 only: Home (map hero, empty state), Create/Edit Memory, My Places, Place Details.
  No auth, backend, planning, timeline, social, filters, notes or galleries.
- State: one persisted Zustand store (`src/store/memories.ts`). Counts, highlighted countries
  and groupings are derived in `src/lib/derived.ts`, never stored.
- Map: MapLibre + OpenFreeMap (`src/lib/map.ts`). Country polygons and bounds are generated by
  `npm run build:countries` into `public/`; join by ISO alpha-2 via `src/lib/countries.ts`.
- `maplibre-gl` must stay in `optimizeDeps.exclude` (vite.config.ts) or its worker 404s in dev.
  In a production build the same worker is resolved from `import.meta.url`, which no bundler
  can see, so `src/lib/map.ts` passes MapLibre a Vite-built worker URL via `setWorkerUrl`.
  Verify map changes against `npm run build && npx vite preview`, not just `npm run dev`.
- Imagery: `src/lib/imagery.ts` resolves one photo per place, cached in `localStorage`
  (`musafir.photos`). Wikipedia/Commons (`src/lib/wikimedia.ts`) is the keyless default;
  Pexels takes priority when `VITE_PEXELS_API_KEY` is set. Memories saved without a photo
  are backfilled on render by `DestinationImage` and written back via `setMemoryPhoto`.
- Checks: `npm run lint`, `npx tsc -b`, `npm run build`.
